UltraTyped.js Compat

new Typed(element, { strings: ['Hello', 'World'], typeSpeed: 50, backSpeed: 30, loop: true, showCursor: true, cursorChar: '|', onComplete: () => { console.log('Done!') } })

Migration Guide
// Before: Typed.js import Typed from 'typed.js' new Typed('#element', { strings: ['Old library'], typeSpeed: 50 }) // After: UltraTyped.js Compat import Typed from '@ultratyped/typed-compat' new Typed('#element', { strings: ['New library!'], typeSpeed: 50 })

Zero code changes needed! Just replace the import.
